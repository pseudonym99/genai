# GenAI

Ein KI-Chatbot basierend auf Chainlit und Pydantic AI, der Google's Gemini-Modell nutzt. Der Bot unterstützt multimodale Eingaben (Text und Bilder) und antwortet auf Deutsch.

## Features

- 🤖 Deutschsprachiger KI-Assistent
- 📸 Multimodale Unterstützung (Text und Binärdaten)
- 💬 Chat-Interface mit Chainlit
- 🔄 Konversationshistorie
- ⚡ Streaming-Antworten


## Start
```
source .venv/bin/activate
chainlit run main.py
```
